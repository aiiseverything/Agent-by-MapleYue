# liteagent 学习手册 · 从零到读懂整个项目

> 这套文档假设你**对 LLM Agent 零基础**。
> 目标有两个，且同等重要：
> **① 学会 Agent 的通用知识**（换任何一个框架都用得上）；
> **② 读懂 liteagent 这个项目的实现**（能和面试官聊、能自己改）。

---

## 0. 先花 3 分钟：这份手册怎么用

### 三种读法，按你的时间选

| 你有多少时间 | 怎么读 | 读完你会 |
| --- | --- | --- |
| **30 分钟** | 只读 [第 1 章](01-agent-basics.md) + 跑一遍 [第 2 章](02-first-agent.md) 的例子 | 知道 Agent 是什么，亲手跑通一个 |
| **半天** | 按顺序读 1 → 2 → 3 → 4 → 5 | 理解 Agent 的核心机制，能自己写工具 |
| **完整学习**（推荐） | 全部 10 章 + 做完第 10 章的练习 | 能独立解释项目每一处设计决策 |

### 一个重要的学习原则

**不要只读，一定要跑。** 这套项目最大的优势是**完全离线、不需要 API key**——
你可以在自己机器上把每个概念都跑一遍看效果。文档里每一段代码都标了可运行命令。

```bash
cd /home/ml-user/workdir/project-3   # 或你 clone 下来的目录
python3 -m unittest discover -s tests -t .   # 先确认环境是好的：1652 个用例全绿
```

如果这条命令通过了，说明你的环境没问题，可以开始学。

## 2. 前置知识自查

这套文档假设你**已经会**下面这些。如果哪条不会，先去补，否则读起来会卡：

| 技能 | 需要到什么程度 | 不会的话 |
| --- | --- | --- |
| **Python 基础** | 函数、类、装饰器、类型注解（`def f(x: int) -> str`） | 先学完 Python 基础语法和装饰器再回来 |
| **命令行** | 会 `cd`、会跑 `python3 xxx.py` | 学 10 分钟就会 |
| **JSON** | 知道 `{"a": 1}` 是什么 | 知道键值对即可 |
| **HTTP 概念** | 知道"请求-响应"和状态码（200/401/429） | 第 3 章会顺带讲 |

**不需要**的：深度学习、Transformer 原理、数学推导、GPU。
**本项目一行模型训练代码都没有**——它只是"调用"已经训练好的模型。

## 3. 关于这个项目本身

### 它是什么

`liteagent` 是一个**零第三方依赖**（只用 Python 标准库）的 Agent 框架。
简历上的定位是：

> **Agent：轻量级 Agent Harness 框架设计与实现**
> 从零构建可扩展的 LLM Agent 开发框架，实现 ReAct 循环与工具系统
> - 核心架构设计：LLM 抽象层、工具系统、记忆管理三层架构
> - ReAct 循环实现：完整的 Thought-Action-Observation 循环、并发工具调用
> - 多 Agent 协作：Sequential、Hierarchical 两种模式，验证代码助手场景

### 真实规模

| 项 | 数值 |
| --- | --- |
| 框架模块 | 41 个 `.py` |
| 框架代码 | 约 2.48 万行 |
| 单元测试 | 1652 个用例，全绿，约 22 秒跑完（共享机器上会浮动） |
| 第三方依赖 | **0**（`numpy`/`rich`/`requests` 都是可选加速，缺了会自动降级） |
| 联网需求 | 测试与示例**全部离线**，不需要 API key |

### 为什么拿它当学习材料

| 优点 | 说明 |
| --- | --- |
| **零依赖** | 没有"魔法"。你看到的每一行代码都是这个项目自己写的，不存在"这是 LangChain 内部实现的，不用管" |
| **离线可跑** | 不需要 API key、不花钱、不联网，所有概念都能当场验证 |
| **有测试** | 1652 个测试既是质量保证，也是**可执行的文档**——想知道某个函数怎么用，看它的测试 |
| **有取舍记录** | `docs/DESIGN_DECISIONS.md` 记录了 27 条设计决策的"背景 / 备选方案 / 为什么这么选 / 代价"，这是最接近真实工程的部分 |

### 它不是什么（诚实的边界）

| 不是 | 说明 |
| --- | --- |
| **不是生产级框架** | 没有经过大规模压测，没有多租户、限流、审计等企业特性 |
| **不是 LangChain 替代品** | 它的价值在于"小而完备、可读、可改"，不是功能覆盖 |
| **没在真实模型上端到端验证过** | 开发环境无外网无 API key，真实 provider 只验证到"请求构造 / 响应解析 / 错误映射"，详见 `docs/VERIFICATION.md` |

## 5. 一个建议的学习节奏

如果你打算认真学，建议这样安排（每段 1-2 小时）：

| 时段 | 做什么 | 产出 |
| --- | --- | --- |
| 1 | 读第 1 章，跑第 2 章的例子 | 建立心智模型 + 环境跑通 |
| 2 | 读第 3、4 章，跟着写 2 个自己的工具 | 理解工具系统 |
| 3 | 读第 5 章，用 `ScriptedLLM` 手动"导演"一次多步推理 | 理解循环（**最重要的一天**） |
| 4 | 读第 6 章，手动触发一次记忆压缩 | 理解记忆 |
| 5 | 读第 7 章，跑通两个多 Agent 示例 | 理解协作 |
| 6 | 读第 8、9 章 | 理解工程细节与全局结构 |
| 7 | 做第 10 章练习 | 检验掌握程度 |

> **最重要的一天是第 3 段。** ReAct 循环是整个项目的心脏，
> 而 `ScriptedLLM` 让你可以像导演一样精确控制"模型每一步说什么"，
> 这是理解循环最快的方式——比读代码快得多。
